# Inbox : idées

Une ligne par idée, la plus ancienne en tête : `- AAAA-MM-JJ · <l'idée> (qui l'a eue)`. Une idée prise devient une ligne de [ROADMAP.md](../../../{{RM}}ROADMAP.md) ou un dossier `docs/plans/<type>-<slug>/`, et sa ligne ici reçoit `[FAIT <branche>]` une fois livrée. Les idées se notent dans le dossier principal, sur `main`, et se committent aussitôt. Un contexte long va dans `fiches/<slug>.md`.
